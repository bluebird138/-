# -人机博弈五子棋软件

该软件作品是一款使用Java语言开发的人机博弈五子棋软件，它界面友好、操作便捷、功能完善，并且运用人工智能启发式的Alpha-Beta剪枝算法，具备较强的博弈能力。
# -作品实现的功能
（1）棋谱的保存和载入
（2）下棋次序的前进和后退
（3）对弈时间的设置
（4）人与人的对弈
（5）人与计算机的博弈
（6）棋况信息提示
（7）对弈困难等级设置等功能

# -运行软件的方法
1.该人机博弈五子棋软件使用Java语言编写，运行之前请先安装好Java虚拟机（Java运行环境）,Java虚拟机推荐使用1.6.0版本。
2.安装好Java虚拟机后，可直接双击运行“AlphaBeta14.5.2.jar”文件运行人机博弈五子棋软件程序。

# -软件的技术特点
本软件运用人工智能启发式的α-β剪枝算法，实现了五子棋的人机博弈功能。其图形化界面基于Java的Swing和AWT技术开发，界面直观友好、操作简便。此外，软件支持棋谱的保存与载入，兼具优秀的五子棋教学与游戏娱乐功能 。
